# 01 DVFS 原理与 P-States 硬件电源状态机

## 1. DVFS (动态电压与频率调节) 理论

GPU 功耗由动态功耗与静态漏电功耗构成：
$$P_{total} = \alpha C V_{dd}^2 f + V_{dd} I_{leakage}$$

- 在高负载计算场景下，升高频率 $f$ 需要同步提升核心供电电压 $V_{dd}$，使功耗随电压平方非线性激增。
- **AVFS (自适应电压与频率调节)**：片内集成可配置环形振荡器（Ring Oscillator），根据制造工艺角（Process Corner）与当前温度动态校准该芯片的最佳工作电压曲线，实现单芯片能效最优化。

## 2. 硬件 P-States 状态机

| 状态 | 核心频率 (Core Clock) | 显存频率 (Mem Clock) | 适用场景 |
| :--- | :--- | :--- | :--- |
| **P0 / P1** | 最高 Boost 频率 (如 2.2GHz+) | 最高传输速率 (如 6.4Gbps+) | 高性能 AI 训练、推理与重载图形渲染 |
| **P5 / P8** | 中等基准频率 (如 800MHz~1.2GHz) | 中等频率 (如 1.6Gbps) | 轻载 2D 桌面显示、轻量级视频播放 |
| **P12 / D3** | 最低休眠频率 (如 200MHz) | 低功耗待机模式 | 待机休眠，关闭所有 GPC 核心供电 |
