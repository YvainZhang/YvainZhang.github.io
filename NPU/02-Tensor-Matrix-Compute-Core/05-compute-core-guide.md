# 05 计算核心工程问题排查与规避

## 1. 常见计算核心故障排查表

| 故障现象 | 根因诊断 | 规避与解决方案 |
| :--- | :--- | :--- |
| **阵列算力利用率极低 (< 30%)** | 矩阵尺寸过小，导致脉动阵列填充与排空阶段（Skew Bubbles）占比过大 | 编译器执行多算子拼接（Operator Fusion）或 Batching 聚合 |
| **INT8 矩阵乘计算结果溢出** | 累加器位宽设计过小（如仅 16-bit 累加器），超出最大数值范围 | 必须配置至少 24-bit 或 32-bit 硬件累加寄存器 |
| **Softmax 精度严重偏差** | LUT 查找表在输入极大或极小时发生饱和截断 | 引入动态减去最大值（Online Softmax: $x - \max(x)$）归一化电路 |
