# 01 Scratchpad SRAM 物理架构与 Cache 本质区别

## 1. Scratchpad SRAM vs 传统硬件 Cache 对比

| 维度 | 传统硬件 Cache (CPU/GPU) | Scratchpad SRAM (NPU) |
| :--- | :--- | :--- |
| **寻址与控制方式** | 硬件透明控制，通过 Tag 比对与 LRU 替换算法 | **软件显式编址（Directly Addressable）**，由编译器精确指定地址 |
| **时延与确定性** | 存在 Cache Miss 颠簸，执行时延不确定 | **100% 确定性单周期/固定周期访问**，无任何 Tag 检查开销 |
| **硬件面积与功耗** | Tag 阵列、一致性控制与替换逻辑占 15%~25% 面积 | **纯 SRAM 存储阵列**，面积利用率高达 95%+，功耗极低 |
| **数据生命周期** | 硬件动态淘汰，容易发生 Cache 污染 | 编译器根据张量生命周期精确静态分配与复用 |
