# 02 硬件数据排布格式转换 (NCHW 到 NC4HW4)

## 1. 为什么需要通道对齐格式 (NC4HW4 / NC8HW8)

脉动阵列和 SIMD VPU 每次必须连续读取多个通道（如 4、8 或 16 个通道）的数据以喂饱并行 MAC：
- **传统 NCHW 格式**：同一位置不同通道的数据在内存中相隔 $H \times W$ 远，无法单周期连续读取。
- **硬件 On-the-Fly 格式转换器**：Tensor DMA 在从 DDR 读入数据的流动过程中，**由硬件流水线实时完成转置重排（Transpose-on-the-Fly）**，存入 SRAM 时已是对齐的 NC4HW4 格式，软件开销为 0。
