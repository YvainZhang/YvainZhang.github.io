# 05 车载 A2B 掉线与 TWS 丢包案例

## 1. 案例背景：车辆急加速时 A2B 音频断连与商场 TWS 蓝牙破音

在端侧音频落地中，两类典型的“物理环境突变引发断流”故障最考验工程师经验：
1. **车载故障**：新能源汽车在深踩油门急加速或高压快充时，车顶的 A2B 麦克风阵列节点突然报告总线断链，语音识别彻底中断。
2. **TWS 故障**：用户佩戴无线耳机进入人流密集的商场或将手机放入牛仔裤后口袋时，耳机声音频繁出现“噼啪”丢包卡顿。

### 修复手段
1. **A2B 节点加固**：
   - 节点入口端追加专门的**共模扼流圈（Common Mode Choke, 阻抗在 100MHz 时 $> 1000\Omega$）**与 TVS 阵列；
   - 将从节点收发器的锁相环环路带宽调整为更加抗扰的稳健模式。
2. **TWS 射频与重传策略加固**：
   - 启用 BLE Audio 的动态自适应重传机制（Adaptive Retransmission）；
   - 优化耳机天线净空区，采用 LDS 激光直接成型天线技术将天线辐射效率从 $35\%$ 提升至 $60\%$，彻底解决人体遮挡丢包卡顿。
