# 02 Audio Precision 测试与可追溯证据

## 1. 仪器不是“绝对纯净”的参考

音频分析仪适合低噪声、低失真的定量测试，示波器适合瞬态、电源和时序观察。是否能分辨 DUT 的指标取决于仪器残余、量程、带宽、连接和校准，不能仅凭 ADC 位数推导测量能力。

先做同设置下的回环基线；仪器与 DUT 噪声接近时，结果包含两者贡献。未经噪声独立性与不确定度分析，不能简单相减 dB 数字。

## 2. 每条曲线都需要条件

| 测试 | 必须记录 | 常见误判 |
| --- | --- | --- |
| THD+N vs frequency | 输入电平、输出负载、带宽、加权、量程、滤波 | 把不同带宽的结果直接比较 |
| 幅频响应 | 参考频率、激励幅度、增益、耦合 | 把仪器/负载响应算成 DUT |
| 噪声与 FFT | 输入端接、静音状态、FFT 点数、窗、平均方法 | 把每 bin 噪声当积分噪声 |
| 串扰 | 激励声道、受测声道端接、参考幅度 | 把线缆串扰当芯片串扰 |
| 动态范围 | 测试方法版本、低电平激励、滤波与校正 | 将静音自动门控结果当有效动态范围 |

THD+N 的分母可能按测量定义取基波或总信号，应注明具体仪器指标。0 dBFS 不是所有模拟链路都安全的扫频输入；先确认余量，避免数字满幅对应的模拟输出过载。

## 3. Class-D 连接安全与前端保护

BTL 输出两端都可能带开关共模，不能把任一扬声器端当作地夹接地。先核对分析仪输入的差模/共模额定值、衰减器与负载功率，并按目标器件参考接法连接。

用于限定测量带宽的滤波，与防止分析仪模拟前端过载的外置预滤波不是一回事。后级数字低通不能挽救已经过载的前端；具体滤波器应依据开关频率、电平、仪器输入能力及测试方法选择。

参考：[Audio Precision 关于 AES17 与 Class-D 预分析滤波的说明](https://www.audioprecision.com/news/selecting-appropriate-aes-17-pre-analyzer-filters-for-the-2700-series-analyzers)。该文针对特定仪器系列，不能把其附件要求泛化到全部型号。

## 4. 真实截图采集清单

当前专题未附可核验的真实仪器截图。以下是待采集证据，不是已经完成的实验：

| 证据 | 应展示什么 | 必须随附 |
| --- | --- | --- |
| I2S 建立/保持违规 | 接收端 BCLK 与 DATA 的同次捕获、阈值和游标 | 器件时序规格、探头、采样率、带宽、负载 |
| I2S 正常对照 | 同配置下合法边沿与解码 | 相同时间基准、slot/位宽/极性 |
| 逻辑分析仪解码 | 已知 PCM 模式与左右声道数据 | 原始工程文件、解码设置、测试模式 |
| THD+N 扫频 | 频率轴、指标单位、正常/异常对照 | CSV、工程配置、输入电平、负载、滤波 |
| 噪声 FFT | 噪声谱与可疑离散杂散 | 窗、点数、平均、带宽、接地与供电条件 |

建立/保持时间从接收器规定的阈值与采样边沿测量；探头偏斜和负载会影响结果。数字逻辑分析仪的阈值判决不能证明模拟波形满足全部时序、电平与过冲要求。

## 5. 发布证据包

每组截图配唯一实验编号，保存板卡版本、固件提交、仪器型号/校准状态、接线图、日期、原始数据和操作步骤。裁图不能隐藏单位、量程或失败样本；曲线必须标注“实测”或“模型计算”。

删除客户名称、序列号、内部路径和网络信息，并确认素材公开权限。拿到真实素材后，先核对数据与配置，再嵌入本页和接口时序章节；不以 AI 生成图代替示波器或 AP 原始捕获。
